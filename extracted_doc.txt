ABSTRACT
The Online Learning Management System (LMS) is a comprehensive web-based educational platform developed to simplify and automate academic activities within educational institutions. With the rapid growth of digital learning and online education, there is an increasing need for an efficient system that enables students, teachers, and administrators to interact through a centralized platform. Traditional methods of managing courses, assignments, attendance, examinations, and academic records involve significant manual effort, paperwork, and time consumption. These challenges often result in data redundancy, communication delays, and difficulties in tracking student performance. The proposed Online Learning Management System addresses these issues by providing a secure, user-friendly, and efficient digital learning environment.
The system is designed using Python Flask as the backend framework, SQLite as the database management system, and HTML, CSS, and JavaScript for the frontend user interface. The platform supports multiple user roles, including students, teachers, and administrators. Students can register and log in to the system, browse available courses, enroll in courses, access study materials, submit assignments, attend quizzes, monitor attendance records, view academic progress, apply for leave, and download course completion certificates. Teachers can create and manage courses, upload study materials, prepare assignments and quizzes, monitor student performance, maintain attendance records, send notifications, and manage academic events. Administrators are provided with tools to manage users, courses, and system activities while ensuring smooth operation of the platform.
One of the key features of the system is its centralized database architecture, which allows all academic information to be stored and retrieved efficiently. The course management module enables teachers to organize learning resources and make them accessible to students at any time. The assignment management module facilitates online submission and evaluation of assignments, reducing paperwork and improving accessibility. The quiz management module allows teachers to conduct assessments digitally and automatically evaluate student performance. Attendance management and progress tracking modules help students and teachers monitor academic achievements effectively. In addition, the notification system and academic calendar improve communication by informing users about important academic events, deadlines, examinations, and announcements.
The project also includes a certificate generation module that automatically generates digital certificates for students who successfully complete their courses and assessments. This feature reduces manual effort and ensures quick delivery of certificates. Furthermore, the system incorporates leave management and profile management functionalities, allowing students to update personal information and submit leave requests online. These integrated features contribute to a more organized and efficient educational environment.
The Online Learning Management System offers numerous benefits, including improved accessibility, reduced administrative workload, enhanced communication, secure data management, and better monitoring of student performance. By integrating multiple academic functions into a single platform, the system supports both teaching and learning processes while promoting digital transformation in education. The developed system demonstrates how modern web technologies can be effectively utilized to create a scalable and reliable learning environment that meets the evolving needs of educational institutions.
The proposed system is highly flexible and can be adapted to various educational environments such as schools, colleges, universities, and training institutes. The platform supports continuous learning by providing students with access to academic resources at any time and from any location. The integration of digital learning tools enhances student engagement and encourages self-paced learning. The system also improves transparency by allowing students to monitor their academic performance and progress regularly. Through automation of routine academic tasks, educational institutions can reduce operational costs and improve overall productivity. The scalable architecture of the system enables future enhancements and integration with emerging educational technologies. Thus, the Online Learning Management System serves as a reliable and effective solution for modern digital education.

[Heading1] 2.1 English Course Online Learning System Design based on MVC
The research paper titled “English Course Online Learning System Design based on MVC” was proposed by Fang Li-xia in 2015. The main objective of this study is to develop an online learning platform that supports teaching and learning activities through a web-based environment. The system is designed to provide students with online access to educational resources, assignments, examinations, and communication facilities while enabling teachers and administrators to manage academic activities efficiently. The study highlights the increasing importance of online learning due to the rapid growth of internet technologies and the need for flexible educational systems. 
The proposed system includes several important modules such as personnel management, question bank management, courseware management, resource management, bulletin management, online learning, online examinations, and communication forums. Students can access learning materials such as PPT presentations, teaching videos, practice questions, and homework resources through the platform. Teachers can upload educational content, manage assignments, create examinations, and interact with students. The system also supports online testing with automatic evaluation and chapter-wise practice activities. 
The authors implemented the system using the MVC (Model-View-Controller) architecture, which separates the application into three layers: Model, View, and Controller. This architecture improves maintainability, scalability, and system performance. The system utilizes the Struts framework and Hibernate technology for database management and data persistence. The MVC design enables efficient interaction between users, application logic, and the database while maintaining security and flexibility. 
The paper emphasizes that online learning systems play a significant role in modern education by allowing students to learn remotely and access educational resources anytime and anywhere. The system provides a platform for teacher-student interaction, online examinations, homework evaluation, and resource sharing. The study concludes that the proposed online learning system offers security, stability, high performance, cross-platform compatibility, and effective management of educational resources. It successfully supports students’ online learning activities and improves the overall quality of education.

LMS platforms support online learning by offering course materials, assignments, assessments, communication tools, and performance tracking features. The main goal of an LMS is to improve accessibility, flexibility, and efficiency in education.
[Heading2] Web-Based Application
[NormalWeb] A web-based application is software that operates through a web browser using internet technologies. Users can access the application from any location without installing additional software. The Online Learning Management System is developed as a web application using HTML, CSS, JavaScript, and Python Flask. This approach improves accessibility and enables users to access academic resources anytime and anywhere.
[Heading2] Client-Server Architecture
[NormalWeb] The LMS follows a client-server architecture. In this architecture, the client (web browser) sends requests to the server, and the server processes those requests and returns the appropriate response. The frontend interface acts as the client, while the Flask application acts as the server. This architecture enables efficient communication between users and the database.

@app.route("/assignments")
def assignments():

        return redirect("/student")
    student = session["user"]
    cursor.execute("SELECT * FROM assignments")
    assignment_list = cursor.fetchall()
    assignment_data = []
    for assignment in assignment_list:
        cursor.execute("""
        SELECT status
        FROM submissions
        WHERE student_name=? AND assignment_title=?
        """, (student, assignment[1]))
        result = cursor.fetchone()
        status = result[0] if result else "Pending"
        assignment_data.append({
            "id": assignment[0],
            "title": assignment[1],
            "due_date": assignment[2],
            "description": assignment[3],
            "status": status
        })
    return render_template(
        "assignments.html",
        assignments=assignment_data

        student = session["user"]
        result = "PASS" if score >= total/2 else "FAIL"

        INSERT INTO quiz_results

            score,
            total,
            result
        )
        VALUES
        (
            ?,
            ?,
            ?,
            ?
        )
        """,
        (
            student,
            score,
            total,
            result
        ))
        conn.commit()
    return render_template(

@app.route("/teacher_marks", methods=["GET", "POST"])
def teacher_marks():
    if "teacher" not in session:
        return redirect("/teacher")
    cursor.execute("SELECT name FROM users")
    students = cursor.fetchall()
    if request.method == "POST":
        # Remove old marks
        cursor.execute("DELETE FROM marks")
        for student in students:
            student_name = student[0]
            assignment = int(request.form.get(f"assignment_{student_name}", 0))
            quiz = int(request.form.get(f"quiz_{student_name}", 0))
            total = assignment + quiz
            if total >= 90:
                grade = "A+"
            elif total >= 80:
                grade = "A"
            elif total >= 70:
                grade = "B"
            elif total >= 60:
                grade = "C"
            elif total >= 50:
                grade = "D"
            else:
                grade = "F"
            cursor.execute("""
            INSERT INTO marks
            (student_name, assignment_marks, quiz_marks, total_marks, grade)
            VALUES (?,?,?,?,?)
            """, (
                student_name,
                assignment,
                quiz,
                total,
                grade
            ))
        conn.commit()
        return redirect("/teacher_dashboard")
    return render_template(
        "teacher_marks.html",
        students=students
    )

@app.route("/quiz", methods=["GET","POST"])

    questions = cursor.fetchall()

    if request.method == "POST":

            score,
            total,
            result
        )
        VALUES
        (
            ?,
            ?,
            ?,
            ?
        )
        """,
        (
            student,
            score,
            total,
            result
        ))
        conn.commit()
    return render_template(
        "quiz.html",
        questions=questions,
        score=score,
        total=total,
        result=result
    )

@app.route("/teacher_marks", methods=["GET", "POST"])
def teacher_marks():
    if "teacher" not in session:
        return redirect("/teacher")
    cursor.execute("SELECT name FROM users")
    students = cursor.fetchall()
    if request.method == "POST":
        # Remove old marks
        cursor.execute("DELETE FROM marks")
        for student in students:
            student_name = student[0]
            assignment = int(request.form.get(f"assignment_{student_name}", 0))
            quiz = int(request.form.get(f"quiz_{student_name}", 0))
            total = assignment + quiz
            if total >= 90:
                grade = "A+"
            elif total >= 80:
                grade = "A"
            elif total >= 70:
                grade = "B"
            elif total >= 60:
                grade = "C"
            elif total >= 50:
                grade = "D"
            else:
                grade = "F"
            cursor.execute("""
            INSERT INTO marks
            (student_name, assignment_marks, quiz_marks, total_marks, grade)
            VALUES (?,?,?,?,?)
            """, (
                student_name,
                assignment,
                quiz,
                total,
                grade
            ))
        conn.commit()
        return redirect("/teacher_dashboard")
    return render_template(
        "teacher_marks.html",
        students=students
    )
